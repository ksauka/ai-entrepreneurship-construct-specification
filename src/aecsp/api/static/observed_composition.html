How this analysis works

The selected dataset and coding model define the analytical population. Filter dimension and Filter value then condition every chart and matrix on one exact coded subgroup. Full retains all papers after those selections. Observed excludes only the missing or unspecified categories registered for the dimension being displayed.

The nested matrix crosses any two different dimensions within the same population. Counts, row percentages, column percentages, and the supporting papers are alternative views of the same cells; they do not imply causal order.
